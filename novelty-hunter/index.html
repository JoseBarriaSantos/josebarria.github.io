Changelog

  • 2026-08-06 Sped up filtering stage (bottleneck) by 10x with Zobrist Hashing.
  • 2026-05-19 Massive UI/UX improvement. Facilitated usage by swapping API key with Lichess Login. Other fixes and features added like game export.
  • 2026-05-18 Complete UI revamp. It wasn't clear what Novelty Hunter is for. Now it is: finding opening ideas. Added position and color filters and unburdened the user by not having to drop pgn.
  • 2026-05-16 MASSIVE UPGRADE. Mariana had the brilliant idea to use concurrency in the API calls making a batch of 700 games go from taking 90 mins down to 3!
  • 2026-04-18 Increased general rarity scores by 100%+ because they were too low.
    Changed early nov function to (15 - x)/10 so that move 5 gets 1.0, move 10 gets 0.5 and move 15 gets 0.
    Added option to filter out custom tournaments.
    Removed novelties textbox.
  • 2026-04-17 Fixed bug with efficiency score: with the old weights white was getting a max of 0.9 efficiency score. SF score now has full weight so max is 1.
